# Arquivo

Código que saiu do app, guardado para o caso de querer voltar a usar.

- `guia-do-dia.js`: o guia do dia que ficava no topo da tela inicial (blocos de horário com as tarefas, as partes de
  estudo do dia, as faltas a compensar e as revisões). Foi removido na reorganização da tela inicial. O arquivo tem o
  CSS, as funções, as ações de clique e o formulário de ajuste, como estavam, e lista no cabeçalho as funções do app
  de que ele depende.
